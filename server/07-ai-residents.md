# 07 · 两个 AI 住户:老麦和小麦

> 这台服务器上住着**两个 AI**,而它们是**完全不同的两种东西**,经常被混成一个:
>
> - **老麦** —— 一个**村民 NPC**,站着不动、被搭话就回话,靠 McAI 插件跑在服务端里。
> - **小麦** —— 一个**以真人玩家身份登录进来的机器人**,自己走路、砍树、盖房子、打怪、被怪打死。
>
> 一句话分清:**老麦在服务端里,小麦在服务端外面。** 老麦是插件,小麦是客户端。
>
> 这一篇的重点不是"我们装了两个 AI",而是它们共用的那条设计原则:
> **本服规则必须原样透传,不能让小模型复述。** 这条是拿实测换来的,后面有数字。

---

## 一、一眼看清两个的区别

| | **老麦** | **小麦(XiaoMai)** |
|---|---|---|
| 是什么 | AI 村民 NPC | AI 玩家 |
| 跑在哪 | 服务端插件(**McAI**) | 服务端**外面**,用客户端协议连进来 |
| 在玩家列表里吗 | 不在(它是 NPC) | **在** —— 和孩子一样占一个玩家位 |
| 会动吗 | 不会走路探险 | 会走路、挖掘、合成、打怪、盖房子 |
| 怎么触发 | 被叫名字,或玩家走进 **12 格** | 被叫名字才说话;行动不需要谁触发 |
| 会不会说错本服规则 | **10 个高频问题不会**(命中就吐预写好的答案);其余问题走模型,**会** | 它不负责回答规则问题 |
| 出事了会怎样 | 玩家问路没人答 | **它会在世界里留下痕迹** —— 挖掉方块、放下箱子 |
| 详细笔记在哪 | 就这一篇 | [`docs/`](../docs/) 一整个目录 |

**最后一行那个差别是关键**:老麦坏了只是"没人搭话",小麦坏了会**改变一个有真人在玩的世界**。
所以这个仓库里关于"不碰别人东西"的那一整套护栏([`docs/04`](../docs/04-guardrails.md))是为小麦写的,
老麦一条都不需要。

## 二、老麦:配置逐项

配置文件开头两行,原文照抄:

```yaml
# 这个文件由后台「AI 村民」页面自动生成,手改会在下次保存时被覆盖。
# 生成时间: 2026-09-17T00:21:12+09:00
```

**这两行本身就是最该记住的一条**:老麦的配置**不是手写的**,是后台一个网页生成的。
在服务器上直接 `vim` 改它,下一次有人在后台点保存,改动就没了。

### 模型和预算

**先说清楚:素材里只有字段名和值,没有任何一行注释解释"为什么是这个值"。**
下面第三列是我的读法,**不是配置里写的理由**:

| 字段 | 值 | 我的读法(⚠️ 推测) |
|---|---|---|
| `enabled` | `true` | 在线 |
| `model` | `qwen3:8b` | 一个**跑在局域网里的小模型**,不是云端大模型(具体地址不进这个公开仓库) |
| `num-predict` | `200` | 生成长度的上限 —— 游戏聊天框装不下长篇 |
| `temperature` | `0.6` | 中等。聊天要有点人味,但不能太飘 |
| `history-turns` | `4` | 只记最近 4 轮对话。历史越长,提示词越长、越容易被带偏 |
| `timeout-seconds` | `60` | 等模型最多 60 秒 |

`timeout-seconds: 60` 单看很离谱 —— 谁会在游戏里等一分钟?
这里有一条**已经实测过的**背景值得摆出来:**老麦和小麦共用同一批本地算力。**
[`docs/13 §四`](../docs/13-magic-numbers.md) 记的就是这件事 ——
机器人把决策间隔下限拍成 300 毫秒,把本地模型打满,
**老麦的回话延迟从 443 毫秒涨到 10156 毫秒**;把下限提到 2500 毫秒之后回落到 3384 毫秒。
还有更坏的一次:8GB 内存的机器上塞 `qwen3:8b`,模型留不住、每次重新加载,
**对话 NPC 每次要等 30 秒、而且返回空**([`docs/03 §二`](../docs/03-local-small-model.md))。

> ⚠️ **这一段是我的推测 —— 素材里没有任何记录说 60 是怎么定出来的。**
> 只能说:在一台会被邻居打满的共享模型机上,60 秒更像"宁可让它等也别报错"留的余量,
> 而不是"觉得模型慢"。**这是一种读法,不是配置里写的理由。**

### 身份和说话方式

| 字段 | 值 |
|---|---|
| `bot-name` | `老麦` |
| `reply-prefix` | `&a[村民 老麦]&r ` |
| `fallback-reply` | `哈姆~ 这个老麦不太想聊,咱说点建造和冒险的事儿呗!` |

`&a` 是绿色、`&r` 是重置 —— 所以孩子在聊天框里看到的是一句绿色的
`[村民 老麦]` 开头。**前缀是硬性的**:不管答案来自模型还是来自标准答案,都带这个头,
玩家一眼能分清"这句是村民说的"还是"这句是哪个孩子说的"。

### 什么时候会开口

| 字段 | 值 | 含义 |
|---|---|---|
| `triggers.on-name` | `true` | 聊天里提到它的名字 → 回 |
| `triggers.near-npc` | `true` | 玩家走近 → 回 |
| `triggers.npc-radius` | `12` | 近到 **12 格**算"走近" |
| `cooldown-seconds` | `6` | 同一次触发之后 **6 秒**内不再说话 |
| `max-concurrent` | `2` | 最多 **2 个**请求同时在跑 |

后两个数字值得单独说。**配置里同样没写它们为什么加**,但放回"模型机是共享的"这个背景,
它们的效果不止是"防刷屏",更像在**保护共用的那台模型机**:

- **`max-concurrent: 2`** —— 三个孩子同时围着它说话,第三个请求不会再往模型上压。
  上面那条 10156 毫秒的教训说明,这台模型机是**会被打满**的共享资源。
- **`cooldown-seconds: 6`** —— 12 格触发范围里,一个孩子来回走两步就能反复触发。
  没有冷却的话,光"路过"就能把额度烧光。

## 三、三个字段各管一层:`persona` / `facts` / `quick-answers`

这是老麦配置里最值得学的结构 —— **同一件事按"能不能编"分成了三层**:

| 字段 | 管什么 | 允许模型自由发挥吗 |
|---|---|---|
| `persona` | 它是谁、怎么说话 | ✅ 完全放开 |
| `facts` | 本服真实规则,塞进提示词 | ⚠️ 走模型,会被复述、会被改写 |
| `quick-answers` | 预写好的标准答案 | ❌ **命中就原样吐出,根本不问模型** |

### `persona`:人格,这一层可以编

原文里有几句写得很具体,值得单独拎出来:

```
你不是机器人、不是程序、不是 AI —— 你就是一个村民,绝不要说自己是 AI,
也绝不要提到「模型」「提示词」「系统设定」这类词。
```

```
⚠️ 来玩的大多是十几岁的中学生(16 岁上下),不是小孩子 ——
说话别哄小孩、别用叠词、别过度感叹、别把话嚼碎了喂,当成同辈聊天就对了。
```

```
只输出纯文本:不要用任何 Markdown 符号(星号、井号、列表编号),也不要用 emoji 或颜文字
——游戏聊天框显示不出来,玩家只会看到一堆方块和星号。
```

这三条的性质完全不同,别当成一类:

| 这条约束 | 它在防什么 | 违反了会怎样 |
|---|---|---|
| 不许说自己是 AI | 破坏沉浸感 | 玩家体验变差 |
| 别哄小孩、当同辈聊 | **用户画像搞错** | 16 岁的孩子被当成 6 岁的哄 |
| 不要 Markdown / emoji | **渲染层限制** | 聊天框显示成一堆方块和星号 —— 这是**功能性的** |

最后一条尤其容易漏。模型默认会输出 Markdown,而**游戏聊天框不是 Markdown 渲染器**。
写提示词的时候顺手写一句"要有条理、分点说明",就等于在要求它输出一堆 `**` 和 `1.`。

另外,人格里写了"说话很口语化、很简短(一般不超过 60 个字)"——
而 10 条标准答案里**有 5 条超过了 60 字**(照素材逐字数的:最长 96 字;
最短的一条只有 19 字,就是「哈姆!打 /spawn 就回出生点啦!」)。
不矛盾:**标准答案不走模型,所以人格里的长度规则管不到它。**

### `facts`:本服规则,这一层不许编

`facts` 开头第一句就把态度写明了:

```
本服叫「羊羊乐园」,Minecraft Java 版 1.21.4。下面是本服真实规则,回答必须照这个说,不许自己编。
```

里面逐条写清了菜单怎么开、怎么赚金币、12 个职业叫什么、怎么圈地、资源世界每天几次、
怎么设家、怎么领每日奖励、怎么回出生点、怎么看玩法、地图在哪、怎么去别的服。
这些内容和这个 `server/` 目录里其他几篇讲的是同一套规则(见
[`03 领地`](03-land-claims.md)、[`05 世界与传送`](05-worlds-and-travel.md))。

`facts` 里还有一句专门写的**防误导**:

> 圈地工具是**金铲子,不是金锄头**。买的是**格数**,工具是**免费**的。

这句之所以要写进配置,是因为"要花钱的是地、不是工具"孩子最容易搞混。

### 🔴 `facts` 里最该学的一条:不知道就说不知道

```
活动、公告、在线人数、谁在线、物价涨跌这些我都看不到。被问到就说「这个我不清楚,你问问管理员」
——【不许说「没有活动」「今天没活动」这种话】,因为我并不知道有没有;也不许自己编一个。
```

这条把**两种不同的"错"**分开了:

| 模型可能说 | 性质 |
|---|---|
| "今天有个挖矿比赛" | 编了一件**不存在**的事 |
| "今天没有活动" | 编了一个**它无权作出的判断** |

第二种更阴,因为它听起来像一句谨慎的、负责的回答。
**"没有 X" 和 "有 X" 一样是断言** —— 老麦看不到活动列表,它两句都没资格说。
配置里用方括号强调的就是这一句。

> 给一个不知道的模型配"不知道就说不知道",**必须把否定句也堵上**。
> 否则它会用"没有"来假装自己知道。

## 四、🔑 标准答案机制:命中就原样吐出

`quick-answers` 一共 **10 条**,覆盖 10 个本服高频问题:

| # | 话题 | 答案里最要紧的信息 |
|---|---|---|
| 1 | 资源世界 | 全服 49 个,每人每天 5 次,里面不能圈地,主世界的家不受影响 |
| 2 | 圈地 | 三步:买格数 → 免费领金铲子 → 点两个对角 |
| 3 | 职业 | 12 个,逐个列名 |
| 4 | 赚钱 | 两条路:职业工资 / 商店「出售手中」 |
| 5 | 商店 | 建筑、工具、食物、红石、装饰、矿物 六类 |
| 6 | 我的家 | 可以设 3 个家 |
| 7 | 每日奖励 | `/rewards` |
| 8 | 出生点 | `/spawn` |
| 9 | 世界传送 | Strix:主大厅、生存世界、空岛世界 |
| 10 | 地图 | 网站 `map.v2good.com` |

挑三条贴原文(**这些字是逐字发给孩子的,不经过模型**):

```
哈姆!圈地三步走:① 菜单里点「领地」,用金币买领地格数(1格=1金币,100格差不多是10×10的地);
② 还是在「领地」菜单里,免费领一把金铲子;③ …
```

```
哈姆!一共12个职业:酿造、建筑、制作、挖掘、附魔、探险、农夫、钓鱼、猎人、矿工、武器匠、伐木。
菜单里点「职业」就能选,里面还能看「收入明细」和「我的统计」!
```

```
哈姆!打开网站 map.v2good.com 就能看整个世界的地图,还能看到大家现在在哪儿!
```

注意每条都以 `哈姆!` 开头 —— **口头禅是手写进标准答案里的**,
这样"不问模型"的那条路和"问模型"的那条路听起来是同一个村民,玩家察觉不到切换。

### 为什么不让模型自己答:三个实测数字

这是整个仓库里**最耐久的一条结论**,原始记录在
[`docs/03 §四`](../docs/03-local-small-model.md):

| 怎么问 | 正确率 |
|---|---|
| 不给资料,直接问配方/规则 | **3B / 7B / 14B 全错**(而且答得很笃定) |
| 给了资料,让它**复述** | 11 次里 8 次对 ≈ **73%** |
| 给了资料,要求**原样输出** | **100%** |

还有一次线上观察:问"这个服务器有哪些职业",**连问 3 次只有 1 次列全**。

73% 听起来还行,放到这个场景里就不行了:

- 12 个职业列表漏掉 1 个,孩子照着找那个职业,**找不到**;
- "1 格 = 1 金币" 说成 "10 格 = 1 金币",孩子**照着算钱**;
- "每天 5 次" 说成 "每天 3 次",孩子**少玩两次**。

**每一次错都会被一个真人当真。** 而 27% 的错误率在聊天里几乎不可能被发现 ——
没有人会去核对村民说的话。

> **换更大的模型解决不了这个问题。**
> 凡是有标准答案的东西(规则、配方、清单),命中就**逐字吐出**,别让模型转述。
> 73% → 100% 这一跳,不是靠模型能力换来的,是靠**把模型从这条路上拿掉**换来的。

### 这个机制的代价:同一条规则存了两份

`facts` 里写着「资源世界 → …全服49个,每人每天限5次」,
`quick-answers` 第 1 条里又写了一遍「全服一共49个……每人每天最多去5次」。

**同一条规则在两个字段里各存了一份。** 这是标准答案机制必须付的代价:
命中关键词走 `quick-answers`,没命中但问到相关的走 `facts` + 模型。
改规则的时候**两个地方都要改**,只改一处 = 两条路会说出不一样的话。

### 🔴 已经发生了一次:老麦嘴里的规则过期了

这不是假设,是两个时间戳直接对上的 —— 但**两条证据来源不同**,得说清楚:

| 证据 | 时间 | 出处 |
|---|---|---|
| McAI 配置的生成时间 | `2026-09-17T00:21:12+09:00` | **这批素材**(配置文件开头第二行) |
| 资源世界改成"第 6 次起每次 1 金币" | 同一天 **19:27**(回滚备份文件名里的 `...-20260917-192730`) | 本仓库 [`CHANGELOG.md`](CHANGELOG.md) —— **不在这批素材里** |

也就是说,**配置比改动早了大约 19 个小时**,而老麦至今仍然在说「每人每天最多去5次」。
现在的真实规则是:**前 5 次免费,第 6 次起每次 1 金币**
(`ResWorld` 的 `daily-limit: 5` 并没有改,收费是加在菜单层的 —— 见 [`CHANGELOG.md`](CHANGELOG.md))。

老麦没说错话 —— 它说的是**过期的话**。而孩子问的是"每天能去几次",
得到的答案会让他以为第 6 次去不了。

这条和 [`05 世界与传送`](05-worlds-and-travel.md) 里那条"说明比功能活得久"是同一个病:

> **一个规则改了,它不会自己从菜单、从书里、从 NPC 的嘴里消失。**
> 而标准答案机制把这件事**放大了** —— 因为它 100% 可靠地重复同一句话,
> 包括那句已经不对的。可靠性是双向的。

## 五、小麦:一个以真人身份住进来的 AI 玩家

**这一篇只写"服务器上有这么一号住户"**,它自己的技术笔记在
[`docs/`](../docs/) 整整一个目录里,别在这儿重复。

小麦不是 NPC。它用客户端协议登录,**在玩家列表里占一个位置**,
和孩子一样会死、会掉东西、会被怪追。这批素材里有一条直接证据 ——
服务器控制台 `viaversion list` 的输出(真人的玩家名已脱敏,只保留机器人自己的名字):

```
[1.21.4] (1): [<PLAYER-A>]
[26.1-26.1.2] (1): [XiaoMai]
[26.2] (1): [<PLAYER-B>]
```

**它和真人挤在同一份版本清单里** —— 那一刻在线的三行里,它占一行。
从服务端的角度看,它就是个普通玩家。

### 孩子会怎么碰到它

| 玩家看到的行为 | 怎么实现的 |
|---|---|
| **不主动在公屏说话** | 被点名才开口 —— 和老麦"被叫名字才回"是同一个取舍 |
| **叫它名字会回话** | 走模型 |
| **可以跟它要东西** | **给不给、给多少由模型按人格决定**;而"背包里没有就给不出""不能超过持有量""同一个人 3 分钟只能要一次"**由代码兜住** |
| **它会自己盖房子、砍树、打怪** | 见 [`README`](../README.md) 的"现状(诚实版)" |
| **它不会碰你的东西** | 一整套护栏,见 [`docs/04`](../docs/04-guardrails.md) 和 [`docs/14`](../docs/14-the-gate-only-guards-half.md) |

最后一条是这台服务器上唯一的硬红线 —— **有真人小孩在同一个世界里盖房子**,
所以"不破坏别人的东西"不是加分项。护栏本身也出过事故
([`docs/17 护栏互相拆台`](../docs/17-guardrails-disarming-each-other.md)),不要当成一装就完事。

### 两个住户唯一真正耦合的地方

**它们抢同一批本地算力。** 这是整篇里最该记住的运维事实:

```
小麦的决策间隔下限 300ms  →  本地模型被打满  →  老麦回话 10156ms(孩子要干等十秒才有回音)
小麦的决策间隔下限 2500ms →  排队消失        →  老麦回话 3384ms,而小麦自己的决策次数 23 → 45
```

> **调小麦的参数之前,先想一下老麦。**
> 代价往往落在**唯一有真人在等**的那条路上 —— 详见
> [`docs/13 §四`](../docs/13-magic-numbers.md)。

## 六、改这块的时候注意什么

| 要做的事 | 注意 |
|---|---|
| **改老麦的配置** | 文件开头写着「由后台「AI 村民」页面自动生成,手改会在下次保存时被覆盖」。**在服务器上直接改 = 下次一保存就没了**,要从后台页面改 |
| **改了任何本服规则** | `facts` 和 `quick-answers` **两份都要改**。只改一份 → 模型路径和标准答案路径互相矛盾 |
| **加 / 删一条玩法** | 老麦是至少 4 个"说明散落点"之一(菜单 lore、玩法书三语段、网页玩法页、老麦)。漏掉老麦 = **NPC 继续教一个不存在的功能**(见 [`05`](05-worlds-and-travel.md)) |
| **调小麦的决策频率** | 它和老麦共用本地模型。别把间隔往下压,先看老麦的回话延迟 |
| **想给老麦换更大的模型** | 先读 §四 那三个数字 —— **换模型解决不了规则题**。该做的是往 `quick-answers` 里加一条 |
| **想在提示词里写"分点说明"** | 别写。游戏聊天框不渲染 Markdown,`persona` 里已经明确禁掉了 |
| **降 `timeout-seconds`** | 60 这个值**为什么这么定,素材里没写**,别当成随便填的。降之前先确认本地模型没有被小麦占满,否则孩子会大面积收到 `fallback-reply` |
| **加新的 `quick-answers`** | 记得**照抄口头禅**(`哈姆!`),否则模型路径和标准答案路径听起来像两个人 |
