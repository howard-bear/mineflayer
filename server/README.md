## 这个目录为什么存在

**Owner 的原话:「以后好查询 不然你很快就会失忆的」。**

维护这台服务器的是 AI 助手,而助手的会话记忆会被压缩 —— 今天查清的东西,下一次可能就没了。
记忆文件只有助手自己看得到;**这个仓库是唯一 Owner 和下一个会话都查得到的地方。**

所以规矩是:**服务器的每一次改动,都要在 [`CHANGELOG.md`](CHANGELOG.md) 留一行**,
四要素缺一不可 —— 改了什么 / 改了哪个文件 / 为什么 / **怎么回滚**。

## 🔴 往这里加东西之前,先读这三条

这是一个**公开**仓库。

1. **绝不能进**:任何密码、`secret`/`api-key`/`token`、内网与管理 IP、内部端口、
   管理后台域名、玩家 UUID、玩家真实 IP、任何 32 位以上的十六进制串。
2. **可以进**:游戏内公开地址(本来就印在发给孩子的书里)、玩法规则、菜单结构、
   插件名和版本、价格。
3. **推送前跑扫描器,而且要先验扫描器本身** ——
   拿它扫一遍**明知有密钥**的目录,确认它真的会命中。
   否则你验的是"扫描器没报警",不是"没有密钥"。详见 [10 篇](10-how-this-was-documented.md)。

## 一条写作纪律

**每个数字都要有出处。** 这个目录里的内容全部来自服务器上实地抓取的配置和日志,
不是凭印象写的;凡是抓不到的,各篇结尾的「⚠️ 我没核实的」里都老实列着。

> 一份**说不清出处**的文档,比没有文档更危险 —— 因为它会被当成事实引用。
